# 美容室 LINE AI自動応答 要件定義

作成日 2026-10-21。講座のクライアント回答を基にした提案段階の要件。未確認事項は合意後に確定する。

## 目的と確認済みの事実

繰り返し届く問い合わせへの対応を減らし、オーナーが施術・接客に使える時間を増やす。
問い合わせは1日10〜15件、土日は増える。公式LINEの友だちは約300人。料金改定は半年に1回程度。初期予算10万円以内。月額上限・配信回数・希望納期は下記の練習用条件を採用。現在の対応時間は未確認。

## 練習用に設定した条件

以下は実際のクライアント回答ではなく、練習を進めるための仮定。

- 月額上限：LINE・サーバー・DB・AIの利用料合計で税込12,000円。継続保守は含めない。
- 一斉配信：月2回、各回約300人。LINE公式アカウントの既存配信画面からオーナーが送る。
- 導入希望日：2026年11月6日。10月26日までに条件・原稿・アカウントが揃う前提で、以降約2週間。

## 今回対応する範囲

| ID  | 機能             | 内容と完了条件                                                                                                                       |
| --- | ---------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| F01 | FAQ回答          | 営業時間、料金、予約方法、施術の組み合わせ、駐車場の5分類。オーナー承認済みの情報だけで回答し、言い換えにも対応                      |
| F02 | 有人引き継ぎ     | 不明・予約希望・個別判断が必要な質問に受付案内を返し、オーナー個人LINEへ通知。管理画面の未対応一覧から元の質問を確認。通知失敗も記録 |
| F03 | スマホ管理       | オーナー1名がログインし、FAQとメニュー・料金を編集。保存後の新規問い合わせに反映。未対応を対応済みにできる                           |
| F04 | 一斉お知らせ     | LINE公式アカウント既存の配信画面を使用。設定支援・テスト・操作説明を納品。独自の配信画面は作らない練習用条件                         |
| F05 | 有人対応中の停止 | 引き継ぎ後は該当ユーザーのAI回答を停止。オーナーは公式LINEのチャットで返信し、管理画面で自動応答を再開                               |

予約方法は案内できるが、予約可否・空席・確定は回答しない。パーマとカラーの併用可否は一般方針のみ回答し、髪の状態に応じた判断はオーナーへ引き継ぐ。

## 今回対応しない範囲

予約受付・変更・キャンセルの確定、リアルタイム空き状況、顧客カルテ、決済、多言語、個人に合わせた施術判断、独自の一斉配信管理画面。

## 将来の追加

Phase 2として予約システム・カレンダー連携、顧客情報に基づく案内を別見積もりとする。既存予約ツールと個人情報の扱いを調査してから設計する。

## 品質と運用の提案条件

- AIは登録情報に根拠がある場合のみ回答。不明・矛盾・API障害時は有人案内へ切り替える。
- 管理画面は認証必須、DBはRLSでアクセス制限。LINE署名検証、イベント重複排除、APIキーのサーバー保管、入力長制限、呼び出し回数制限を実装する。
- 質問はClaude APIへ送られることを利用案内に記載。氏名・電話番号を追加収集しない。質問履歴は30日で削除する案。保存期間・削除方針は合意する。
- FAQ回答はReply APIを基本とする。通知は個人LINEへのPush。オーナーの友だち追加と通知先IDの安全な登録を行う。LINE Notifyは使用しない。
- 問い合わせ件数とAIリクエスト件数は別。費用試算は月500リクエスト、1回入力2,000・出力300トークンで仮置き。上限接近を通知し、合意した利用上限でAIを停止して定型案内へ切り替える。
- 無料DBは休止・バックアップ等に制約がある。FAQデータのエクスポート手順と復旧手順を引き渡す。24時間無停止保証は付けない。

## 受け入れ確認

FAQ各分類3件の言い換え計15件を事前承認した正答で確認。範囲外5件は捏造せず引き継ぐ。予約確定を誤案内しない。スマホで料金変更し、新規質問に反映。未認証の編集不可、署名不正拒否、同一イベントで重複通知しない。有人切替・再開・通知失敗時の記録を確認。一斉配信はオーナー承認済みのテスト宛先で確認し、本番顧客への送信は別途オーナーが実施する。

## 効果の測定

導入前1週間の対応件数・所要時間を記録し、導入後2週間と比較する。対象FAQの80％自動解決を仮目標にする。予約や個別相談を含む全問い合わせの80％を保証しない。「30分から5分」は現状実測がないため提案の確約に使わない。

## 承認前に追加確認すること

1. 月額上限は税込12,000円と仮定済み。LINEの現在の契約プランを確認する。
2. 月2回・公式LINEの既存画面を使う条件で進める。
3. 導入希望日は2026年11月6日と仮定済み。現在の対応時間と予約管理ツールを確認する。
4. 店舗の正式な営業時間・価格・住所・駐車場・併用施術方針・予約案内先は何か。
5. 個人LINE通知と手動返信の運用、30日保存、必要なアカウントの店舗名義契約でよいか。

初期8万円税込・期間2週間は学習案件としての仮見積もり。保守は別契約、納品後14日間は合意範囲内の不具合修正を含む案。未確認事項・仕様変更で再見積もりする。
